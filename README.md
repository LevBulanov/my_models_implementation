# my_models_implementation

Учебный репозиторий с реализациями классических алгоритмов машинного обучения «с нуля», преимущественно на NumPy. 

Основная цель проекта — не продакшн-качество и не скорость, а понимание того, как алгоритмы устроены изнутри**: что происходит на каждом шаге обучения, как считаются градиенты, как строятся деревья, как работает кластеризация и т.д.

> Это **не production-ready библиотека**. Код написан в первую очередь для обучения и может не включать оптимизации, устойчивость к крайним случаям и полное покрытие тестами.

## Реализованные модели

#### Линейные модели
- **Linear Regression** — классическая линейная регрессия (аналитическое решение / градиентный спуск)
- **Ridge** — линейная регрессия с L2-регуляризацией
- **Lasso** — линейная регрессия с L1-регуляризацией
- **ElasticNet** — комбинация L1 и L2 регуляризации

#### Деревья и ансамбли
- **Decision Tree (Classifier/Regressor)** — дерево решений с нуля
- **Random Forest (Classifier/Regressor)** — бэггинг над деревьями решений
- **Gradient Boosting (Classifier/Regressor)** — градиентный бустинг над деревьями

#### Кластеризация
- **K-Means** — классический алгоритм кластеризации
- **DBSCAN** — плотностная кластеризация. Для ускорения поиска соседей используется `BallTree` из `sklearn.neighbors`, вся остальная логика (расширение кластеров, определение core/border/noise точек) реализована самостоятельно

#### Нейронные сети
- **MLP** — многослойный перцептрон (прямое и обратное распространение ошибки реализованы вручную)

## Цель проекта

Этот репозиторий создавался для того, чтобы:

- разобраться в математике и логике алгоритмов «руками», а не просто вызывая `model.fit()`
- увидеть, как по шагам работает градиентный спуск, построение дерева, разбиение по плотности и т.д.
- сравнить собственные реализации с эталонными из `scikit-learn` по качеству и поведению на данных
- получить базу для дальнейшего эксперимента (добавление новых алгоритмов, визуализаций, метрик)

---

## Используемые технологии

- **Python 3.x**
- **NumPy** — основная вычислительная библиотека
- **scikit-learn** — используется точечно (например, `BallTree` для ускорения DBSCAN), не как замена собственным реализациям
